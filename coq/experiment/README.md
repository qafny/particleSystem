## Run experiments in the current directory
Run `bash extract.sh` in the current directory. This will extract our Coq definitions to OCaml and compile the resulting OCaml code.

>> bash clean.sh
   clean the temporary files in mother directory


>> bash extract.sh
   This will extract our Coq definitions to OCaml and compile the resulting OCaml code.

>> ./run.sh
   Optinal, skip extraction and generate executable

>> ./extraction/_build/default/run.exe
   run the experiments
